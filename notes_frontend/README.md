# Notes Frontend (React Native, Expo)

Ocean Professional themed notes app with local SQLite storage.

Features:
- Create, view, edit, delete notes
- Local SQLite persistence using expo-sqlite
- Modern, minimalist UI with blue (primary) and amber accents
- Header with app title
- Floating action button for new notes
- Scrollable notes list
- Detail view for editing
- Bottom navigation bar
- Smooth transitions using LayoutAnimation

Run:
- Install deps: npm install
- Start (Metro bundler): npm start (or npm run android / ios / web)
- Android native build:
  1) npm run prebuild:android
  2) npm run build:android
  3) Or manually: cd android && ./gradlew assembleDebug

Notes:
- Built with Expo SDK 53. Uses expo-sqlite and expo-linear-gradient.
- No external navigation dependencies; simple in-app navigator for smooth transitions.
- Gradle build requires the native android/ folder, which is generated by the prebuild step. Without prebuild, running Gradle directly will fail.

Folder structure:
- src/theme.ts: Theme tokens
- src/storage/db.ts: SQLite helpers & CRUD
- src/components/: Header, FAB, NoteCard, BottomNav
- src/screens/: NotesListScreen, NoteDetailScreen, SettingsScreen
- src/navigation/RootNavigator.tsx: Lightweight navigator
